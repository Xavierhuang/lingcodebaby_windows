LingCodeBaby Help

A minimal cross-platform IDE with Claude, cloud deploy, and the Quinny specification language built in. Windows, Linux, and macOS from one codebase.

System requirements

  • Windows: Windows 10 (1809) or later; WebView2 runtime (usually already installed).
  • Linux: Any distro with webkit2gtk-4.1 (Ubuntu 22.04+, Fedora 39+, etc.). Ships as .deb, .rpm, and .AppImage.
  • macOS: 11 (Big Sur) or later.
  • Node.js (for the bundled claude CLI) and an internet connection.

Install

  1. Download the latest installer for your OS from the releases page.
  2. Run the installer (*-setup.exe on Windows; .deb/.rpm/.AppImage on Linux).
  3. Launch LingCodeBaby from the Start menu / launcher.

Prerequisite: the claude CLI must be on your PATH. Install with npm i -g @anthropic-ai/claude-code or the official installer.

Sign in — pick one

The Welcome card on first launch offers four paths. You can revisit it any time from Help → Welcome to LingCodeBaby….

  • LingModel account — LingCode's managed proxy. Recommended for casual use; no personal Anthropic key required.
  • Claude subscription — inherits the credentials from claude login in your terminal.
  • Custom endpoint — any Anthropic-compatible URL (Moonshot Kimi, DeepSeek, LiteLLM, OpenRouter, self-hosted). Config sheet at View → Custom Endpoint….
  • Personal Anthropic key — paste sk-ant-… into the OS Keychain via View → Anthropic API Key…. Used automatically as a fallback when the other paths aren't configured.
Endpoint priority (highest wins): Custom endpoint → LingModel → Personal key → Claude subscription. Change the picker in View → Claude Model to steer between the first two.

Working on a project

  • Open a folder: Ctrl+Shift+O (macOS: ⌘⇧O).
  • New window: Ctrl+N.
  • Save: Ctrl+S.
  • Find in file: Ctrl+F; next/previous with Ctrl+G / Ctrl+Shift+G.

Chat with Claude

The right pane is a live chat that drives the claude CLI as a subprocess. It shows thinking blocks, tool calls, and per-file edits inline. Stop a runaway turn with Ctrl+..

When Claude needs a decision it can ask a multiple-choice question — the app renders each option as a clickable chip.

Quinny (specification language)

Quinny is bundled with LingCodeBaby — no install. It lets the agent write acceptance criteria for correctness-critical logic (pricing, cart math, state machines, validation), then verify the code against them. Not useful for UI/layout tasks.

  • New Quinny Project… — File menu (Ctrl+Shift+N). Prompts for a name + one-sentence description, then runs quinny gen to draft a project.qn.
  • New Quinny File… — right-click in the file tree.
  • Quinny: Check / Show Plan — right-click any .qn file.
  • The agent can also run quinny scaffold and quinny verify itself when the task is correctness-critical.

Deploy to LingCode Cloud

Toolbar button Deploy or File → Deploy to LingCode Cloud (Ctrl+Shift+D). Tars the open folder, uploads it to LingCode Cloud, and returns a public URL. Requires a LingModel/LingCode sign-in.

Preferences and secrets

  • Preferences JSON: stored under your OS config dir (%APPDATA%\com.lingcodebaby.app\prefs.json on Windows; ~/.config/com.lingcodebaby.app/prefs.json on Linux).
  • Secrets in Keychain: the LingCode account token (service LingCode, account lingcode_auth_access_token), personal Anthropic key (service LingCodeBaby, account anthropic_api_key), and custom-endpoint key (service LingCodeBaby, account customEndpointAPIKey).

Auto-update

LingCodeBaby checks for updates a few seconds after launch, and on demand via LingCodeBaby → Check for Updates…. Updates are cryptographically signed — the app refuses any update whose signature doesn't verify against the pubkey embedded at build time.

Report a bug

Open an issue on the GitHub tracker. Include your OS + version, and if it's a Claude/agent bug, the exact prompt that produced it.
